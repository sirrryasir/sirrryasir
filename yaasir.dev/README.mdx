# Yasir Hassan - Portfolio

This repository contains the source code for my personal portfolio and blog, built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/).

## Setup & Compilation

### Installation

Ensure you have [Bun](https://bun.sh/) installed, then clone the repository and install dependencies:

```bash
git clone https://github.com/sirrryasir/sirrryasir.git
cd sirrryasir/yaasir.dev
bun install
```

### Development

To start the local development server:

```bash
bun run dev
```

The portfolio will be available at `http://localhost:4321/` and the local CMS admin at `http://localhost:4321/admin/`.

### Environment Variables

If you need to work with the Decap CMS authentication gateway, link the Vercel project and pull the environment variables:

```bash
npx vercel link
npx vercel env pull
```

## Structure

- `src/`: The main Astro source code (components, layouts, pages).
- `src/content/`: Markdown/MDX files for the blog and project collections.
- `public/admin/`: Decap CMS configuration (`config.yml`).
- `api/`: Vercel Serverless Functions (`auth.ts`, `callback.ts`) that handle the GitHub OAuth flow for the CMS.

## Stack

- **Framework**: Astro 5.x
- **Styling**: Tailwind CSS v4
- **Runtime**: Bun
- **CMS**: Decap CMS (Self-hosted via Vercel Serverless Functions)
- **Deployment**: Vercel
